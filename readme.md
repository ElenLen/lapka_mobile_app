# Лапка

Мобильное приложение для владельцев питомцев: дневник здоровья, соцсеть и совместные прогулки

- **Роль:** UX/UI Designer, Frontend developer
- **Платформа:** iOS (Mobile App)
- **Год:** 2026

## Проблема

Владельцы домашних животных живут в режиме разрозненных данных: прививки в бумажном паспорте, вес и корм в заметках, поиск врача в чатах, а потребность в общении с другими собаководами решается в хаотичных группах мессенджеров. Существующие приложения либо узконаправленные (только трекер здоровья), либо перегруженные (только соцсети без полезных функций).

**Главная боль:** нет единого безопасного пространства, где можно вести дневник питомца, следить за его здоровьем и при этом находить единомышленников для прогулок и общения без переключения между 5 сервисами.

## Результат

Готовый интерактивный прототип, который закрывает потребности и в заботе о здоровье питомца, и в общении с другими владельцами, не перегружая пользователя.
